# 文興遊戲群島

國一・國二跑班資訊科技・個人遊戲作品展（跑二、跑六兩個群島）。由大大小小的空中島拼成的 3D 玩具模型城市，每座島是一位同學的作品，點一下島就能直接玩。

- `index.html`：主網站（Three.js）
- `遊戲程式/`：跑二同學的遊戲（HW1）
- `跑六/跑六遊戲程式/`：跑六同學的遊戲（HW1）
- `_island/`：封面縮圖、島嶼資料、建置腳本 `build.py`

## 更新作品
1. 把新的作業下載包解壓縮，覆蓋各班的「遊戲程式」「遊戲封面」資料夾（新班級在 `_island/build.py` 的 CLASSES 加一行）
2. 執行 `python3 _island/build.py`（需要 Pillow）
3. 把變更推上 GitHub，網站幾分鐘內會自動更新
